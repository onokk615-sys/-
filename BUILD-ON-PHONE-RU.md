# Как получить APK только с телефона

В этом архиве есть GitHub Actions workflow для облачной сборки. ПК не нужен, но потребуется аккаунт GitHub и загрузка исходников в репозиторий.

1. Создай аккаунт на https://github.com/ (если ещё нет) и войди в браузере телефона.
2. Создай новый репозиторий, например `SoentaLauncher`.
3. Загрузи содержимое папки `SoentaLauncher` в репозиторий через веб-интерфейс GitHub. Важно: вместе с `app`, `build.gradle.kts`, `settings.gradle.kts`, `.github/workflows/build-apk.yml` и остальными файлами.
4. Открой вкладку **Actions** в репозитории и выбери **Build Soenta Launcher APK**.
5. Нажми **Run workflow** (или дождись запуска после загрузки файлов), затем открой завершённый запуск.
6. В разделе **Artifacts** скачай `soenta-launcher-debug-apk.zip`, распакуй его на телефоне и установи `app-debug.apk`. Android может попросить разрешить установку из этого источника.

Если GitHub не разрешит загрузить папку целиком, загрузи файлы по одному или через ZIP-распаковщик с функцией загрузки файлов в браузере.

## Ограничение
Этот workflow собирает только Android-оболочку интерфейса SOENTA. Он не включает Minecraft runtime, не устанавливает моды в профиль игры и не превращает макет в полноценный Minecraft launcher. Для этого нужен следующий этап интеграции движка Zalith.
